# Security Policy

## Scope

`palm` is a local CLI for recon workflows. It sends DNS and HTTP requests to targets supplied by the user.

## Reporting

Please report security issues privately by opening a GitHub security advisory or contacting the maintainer through GitHub.

Do not open public issues for exploitable vulnerabilities until a fix is available.

## Notes

- `-takeover` is fingerprint based and should be manually verified before reporting findings.
- TLS certificate verification is relaxed for recon usability.
- Only scan assets you own or are authorized to test.
